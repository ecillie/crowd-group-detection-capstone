# CSC_Capstone

To run the code, do the following:

1. Make sure both yolo.py and results.py are in the same directory.

2. Run this in the command line to make sure all packages are downloaded: pip3 install ultralytics deep_sort_realtime opencv-python pandas

3. Edit the video_output_pairs variable to include your video and output file paths in the following format: [input video path, output results file].

4. Edit the constants at the top of the file to fine tune the parameters.

5. Run the file by changing into the directory and running this in the command line: python3 yolo.py

6. Open results.py and edit OUTPUT_FOLDER to fit your file structure.

7. Edit input_files to include your input file paths.

8. Run results.py.
